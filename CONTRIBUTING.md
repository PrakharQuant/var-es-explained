# Contributing

Thank you for your interest in improving **var-es-explained**!

This is an educational project. Contributions that keep the teaching style (numerical example → intuition → equation) are especially welcome.

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-example`)
3. Make your changes
4. Add or update tests if you change the library
5. Ensure `pytest` passes
6. Open a Pull Request

## Style

- Keep explanations beginner-friendly
- Always show a tiny numerical example before any formula
- Label every chart and table with units (₹ crore) and confidence level
- Cite regulatory sources (BCBS d457, BCBS d352, RBI circulars) with the educational disclaimer
